# Currency converter — Batch 5, tool 19

Route: `/calculators/currency-converter`. Supporting article: 1,715 independently counted words, a 99-word introduction and exactly three FAQs. Uses the existing calculator page, decimal engine, currency registry, directional conversion resolver and rate service.

The converter supports manual single or bid/ask quotes, direct/inverse/two-leg cross paths, available dated daily references and selected-date historical references. Sell-source conversions use direct bid/inverse ask. It separates reference value, provider value and net amount; provider pricing can be entered directly or modeled as a percentage reduction in target units received. Separate percentage/fixed fees are explicitly charged in source currency before conversion or target currency afterward. Observed credited amounts can provide an effective-rate comparison. Zero source amounts do not cause division by zero.

Currency reversal clears provider adjustments and fees. A simple quotation retains its mathematical orientation; crossed manual quotes require re-entry. No wallet connection or transfer execution is provided. Nineteen registered calculation currencies are selectable; reference/historical coverage varies, and unsupported paths require manual quotes.

The shared rate endpoint now accepts a validated historical date. It does not request future/current incomplete UTC days, caches warm fallbacks separately by requested date and preserves original observations. The client keys loaded data to the requested mode/date, preventing an earlier request from silently satisfying a later date. Historical observations after the requested date are rejected. Earlier weekend/holiday observations and differing leg dates are disclosed. Daily references are not live executable prices; manual values never become verified live quotes.

Verification: 36 numerical/service regression groups passed across currency, date-aware API, lot sizing, commission and spread. This includes six currency groups and two API groups; the latter reproduce a provider outage and prove that the wrong requested-date cache cannot be returned. Eighteen browser/regression groups passed across the converter, pip tool, commission, spread and contextual links. Tests cover source/target fees, cross paths, reversed quotes, provider comparison, historical failure/date isolation, share/reset, mobile sizes, SSR default, canonical/sitemap and three FAQs. Production webpack build including TypeScript, ESLint and whitespace checks passed.

Source verification: Frankfurter documentation explicitly states these are reference rates, not live market quotes, and documents historical access. The fetched ECB reference-rate page states the rates are published for information purposes and discourages their use for transactions. Both are linked contextually; no current illustrative rate in the article is presented as a verified observation.
