Snapshot mode measures current decline/recovery from an earlier reference; it does not infer historical maximum drawdown from two amounts. History mode tracks ordered running peaks, current drawdown, maximum percentage and monetary/point declines separately, episode peak/trough/recovery observations and durations. Nonpositive values have no conventional finite percentage recovery. An unrecovered episode never receives an invented future recovery date.

History supports two to 1,000 observations and CSV text/files up to 64 KiB. Dates are all-or-none historical ISO calendar dates and must already increase; they are not silently sorted. Equity and balance are labelled separately. Large tables show the first fifty rows while summaries and the chart use the full series. The original chart uses proportional date spacing or observation spacing, a solid value/index path and dashed running peak; it does not reconstruct unseen intraday values.

Cash-flow choices are explicit: confirmed absence, raw account values, or a scaled performance index assuming all flows occur at interval end. The index multiplies by `(ending raw value − signed flow) / previous raw value`. Adjusted mode requires explicit flow values, including zeros, and rejects undefined capital restarts or unsupported numeric ranges. A withdrawal can reduce raw account value without a performance loss. Adjusted index points are never labelled spendable account money.
